# 游戏隐私保护指引

静态隐私页面，通过 GitHub Pages 从 main 分支根目录发布。

## 哈基米全责

- 简体中文：`hajimi-quanze/?language=zh-CN`
- English: `hajimi-quanze/?language=en`
- 兼容 `language=中文`、`language=英文` 及常见语言地区代码。
- 不支持的语言回退到英文并提示。未传入参数时默认简体中文。

页面按当前游戏代码与 OpenPaaS 官方资料披露本机存档、SUD-GI 官方规则、邮件反馈、未成年人信息处理规则及 GitHub Pages 访问日志。当前已配置平台创建的激励视频广告位；实际播放取决于后台启用、宿主支持和广告填充。正式提供广告前须补充实际广告源和适用的授权流程。协议展示不代表每个宿主的 SDK 实装、后台隐私声明或监护人验证已经验收。

页面不使用第三方字体、统计、外部脚本或 Cookie。
